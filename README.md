# ~*~ Cabz's World ~*~

A GeoCities-era retro remake of my personal portfolio
([modern version](https://cabizaresroelcezar-se.github.io/cabizaresroelcezar/)),
inspired by [Cameron's World](https://www.cameronsworld.net/), a love letter to the Internet of old.

No build step, no framework: hand-written HTML, CSS and a pinch of JavaScript, like it's 1999.

## What's inside
- Old-school Win95 scrollbar (dithered track, ridged silver thumb, pixel arrow buttons)
- Tiled backgrounds, Win95 window chrome, marquees, blink, rainbow WordArt
- "Under construction" sign, visitor counter, 88×31 badges, webring
- Guestbook (contact form via FormSubmit), cursor sparkle trail
- CabzAmp: a Winamp-style player with a Web Audio chiptune + Spotify embed
- Respects `prefers-reduced-motion`; responsive down to phone width

Animated GIFs are real archived GeoCities graphics found via the Internet Archive's [GifCities](https://gifcities.org); see [CREDITS.md](CREDITS.md).

## Run locally
Open `index.html` in a browser, or `npx serve .`

## Deploy
GitHub Pages → Settings → Pages → Deploy from branch `main`, folder `/`.
